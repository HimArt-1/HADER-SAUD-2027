# 🟢 دليل تشغيل whattONE على ويندوز

## 📋 المتطلبات

| المتطلب | الرابط | ملاحظة |
|---------|--------|--------|
| **Python 3.10+** | [python.org/downloads](https://www.python.org/downloads/) | ⚠️ فعّل **"Add Python to PATH"** أثناء التثبيت |
| **Google Chrome** | [google.com/chrome](https://www.google.com/chrome/) | مطلوب لتشغيل بوت الواتساب |

---

## 🚀 التشغيل السريع

### الخطوة 1: تثبيت Python

1. حمّل Python من [python.org](https://www.python.org/downloads/)
2. شغّل ملف التثبيت
3. **⚠️ مهم جداً**: ضع علامة ✅ على **"Add Python to PATH"** في أول شاشة

   ![إضافة Python للمسار](https://docs.python.org/3/_images/win_installer.png)

4. اضغط **Install Now**
5. للتأكد من التثبيت، افتح **CMD** واكتب:
   ```
   python --version
   ```
   يجب أن يظهر رقم الإصدار مثل `Python 3.12.x`

### الخطوة 2: تثبيت Chrome

حمّل وثبّت [Google Chrome](https://www.google.com/chrome/) إذا لم يكن مثبتاً.

### الخطوة 3: تشغيل الأداة

- **انقر مرتين** على ملف `start.bat` 🖱️

هذا كل شيء! ✅ سيقوم الملف تلقائياً بـ:
1. فحص Python و Chrome
2. إنشاء بيئة افتراضية وتثبيت المتطلبات (أول مرة فقط)
3. فتح لوحة التحكم في المتصفح تلقائياً

---

## 🖥️ إنشاء اختصار على سطح المكتب

لتسهيل التشغيل المستقبلي:

1. **انقر مرتين** على ملف `setup_shortcut.bat`
2. ستجد أيقونة **whattONE** على سطح المكتب
3. استخدم الأيقونة لتشغيل البرنامج بنقرة واحدة!

---

## 🌐 استخدام لوحة التحكم

بعد التشغيل، سيفتح المتصفح تلقائياً على:

```
http://localhost:5005
```

### ما يمكنك فعله:

| الميزة | الوصف |
|--------|-------|
| 🟢 **تشغيل البوت** | اضغط زر "تشغيل" ثم امسح QR من واتساب |
| 📥 **استيراد ملف** | ارفع ملف CSV أو Excel بقائمة الطلاب |
| 📝 **القوالب** | اختر قالب الرسالة (غياب، تأخر، استئذان) |
| 📨 **الإرسال** | أرسل الرسائل تلقائياً لأولياء الأمور |

---

## ❓ استكشاف الأخطاء

### ❌ "python غير معروف"
- أعد تثبيت Python مع تفعيل **"Add Python to PATH"**
- أو أضف Python يدوياً من: إعدادات النظام → متغيرات البيئة

### ❌ "فشل تهيئة المتصفح"
- تأكد من تثبيت **Google Chrome**
- أغلق جميع نوافذ Chrome وأعد المحاولة

### ❌ "المنفذ مستخدم"
- أغلق نافذة whattONE القديمة وأعد التشغيل
- أو عدّل المنفذ في ملف `.env`:
  ```
  WHATTONE_PORT=5006
  ```

### ❌ توقف عند مسح QR
1. افتح WhatsApp على هاتفك
2. اذهب إلى **الإعدادات** → **الأجهزة المرتبطة**
3. اضغط **ربط جهاز**
4. امسح رمز QR الظاهر على الشاشة

## ⚙️ إعدادات اختيارية

أنشئ ملف `.env` (انسخ من `.env.example`):

```env
# المنفذ (اختياري، الافتراضي 5005)
WHATTONE_PORT=5005

# مفتاح API للحماية (اختياري)
WHATTONE_API_KEY=your_secret_key
```
