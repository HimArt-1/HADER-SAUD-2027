# متابعة فحص حاضر: ترقية الحزم — 7 سبتمبر 2026

متابعة أحدث: عولج قفل الغياب وسباق الحضور في [تقرير الغياب التلقائي](AUTOMATIC_ABSENCE_AUDIT_2026-09-07.md)، مع اختبار PostgreSQL فعلي. أرقام الفحص أدناه توثق جولة ترقية الحزم السابقة.

## النتيجة الحالية

أصبح `npm audit` لحزم التطبيق الرئيسي يسجل **صفر تنبيهات** بدل 17 عند بداية المتابعة و45 قبل الجولة الأولى. نجح تثبيت نظيف من ملف القفل، و346 اختبارًا، وTypeScript وESLint، وبناء الويب وPWA وبناء ملفات Electron وتغليف تطبيق macOS بمعمارية arm64.

صفر تنبيهات يعني عدم وجود تنبيهات مسجلة في نتيجة npm وقت الفحص لهذه الشجرة. لا يشمل ذلك مكتبات Python أو مشروع الفيديو المنفصل، ولا يثبت خلو كود التطبيق نفسه من جميع الثغرات.

## التحديثات

| الحزمة | الإصدار المثبت بعد التحديث |
|---|---|
| Vite | 7.3.6 |
| Vitest | 3.2.7 |
| إضافة React لـVite | 4.7.0 |
| Electron | 44.2.0 |
| electron-builder | 26.15.3 |
| React Router DOM | 7.18.3 |
| SheetJS / xlsx | 0.20.3 |

- اختيرت إصدارات مصححة محددة، بدل تنفيذ ترقية إجبارية عمياء لجميع الحزم.
- ثُبّتت SheetJS من ملف الإصدار المعلن في [وثائق التثبيت الرسمية](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/)؛ سجل npm باسم xlsx لا يوفّر ذلك الإصدار. يسجل package-lock.json المصدر وبصمة سلامة الحزمة.
- أزيل خيار `future` القديم من HashRouter بعد أن أثبت TypeScript عدم توافقه مع الإصدار 7. اختبارات التوجيه الجديدة تغطي الدخول العام، وتحويل المستخدم المسجل، وروابط التخطيط الداخلي، ورفض دخول المراقب للإدارة، ومسارات الإدارة والكشك وولي الأمر والاستبيان العام.
- احتُفظ بأهداف المتصفحات السابقة في إعداد Vite صراحة لتفادي رفع الحد الأدنى تلقائيًا أثناء [الترقية إلى Vite 7](https://v7.vite.dev/guide/migration).
- انتقل `publisherName` الخاص بـWindows إلى `win.signtoolOptions.publisherName` بعد أن رفض اختبار التغليف الإعداد القديم؛ الإصلاح يطابق بنية التوقيع في [electron-builder 26](https://www.electron.build/v26/docs/win/).
- وُحّد Node على السلسلة 22 في GitHub Actions وDocker و.nvmrc، وأصبح شرط package.json هو `^22.13.0 || >=24.0.0`. نُفذ التحقق باستخدام Node 22.22.1.
- أصبح فحص الاعتماديات في CI مانعًا للبناء عند وجود تنبيه متوسط أو أعلى؛ أزيل `continue-on-error` وربطت مرحلة البناء بنجاح مرحلة الأمان.

أضيفت سبع حالات اختبار للتوجيه في `__tests__/app-routing.spec.tsx` وحالة لقراءة وكتابة Excel بالعربية مع الاحتفاظ بأرقام الطالب والجوال التي تبدأ بصفر في `__tests__/xlsx-parser.spec.ts`.

حزمة الفحص المحلية:

```text
/private/tmp/hader-desktop-audit/mac-arm64/نظام حاضر.app
```

فُحص أرشيف app.asar وتأكد وجود package.json ومدخل electron/main.js وpreload.js وelectron/package.json وdist/index.html. نجاح التغليف وفحص المحتوى لا يثبت نجاح كل الوظائف عند تشغيل التطبيق.

في معاينة إنتاج محلية على المنفذ 5187 ظهرت بوابة الدخول، وعمل تبديل ولي الأمر والتنقل إلى الديمو والدخول التجريبي. لم توجد صور مكسورة أو زيادة في عرض الصفحة في القياس المنفذ. ظهرت رسائل حماية الإنتاج الخاصة بغياب تهيئة Supabase؛ لم تُخفَ هذه الرسائل ولم يُعطّل الحارس.

## ما بقي قبل اعتماد الإنتاج

1. **تهيئة Supabase غير موجودة في البيئة المحلية.** حارس الإنتاج يمنع الوصول الفعلي لقاعدة البيانات؛ عرض الدخول والديمو لا يعني أن تسجيل الدخول السحابي يعمل. يلزم إعداد بيئة اختبار سحابية ثم اختبار الصلاحيات والسياسات والمزامنة بين أجهزة فعلية.
2. **اختبارات سطح المكتب العملية والتوقيع.** حزمة macOS الحالية غير موقعة، ولم تُنشر أو تُثبّت. لم يُختبر تشغيلها التفاعلي أو أجهزة Intel أو مثبت Windows أو توقيع الإصدار الرسمي. إعدادات توقيع الإنتاج بقيت مفعلة؛ الاستثناء كان في أمر الفحص المحلي فقط.
3. **قفل الغياب بعد انهيار الجهاز.** عولج لاحقًا بقفل خاص بمعاملة قاعدة البيانات بدل القفل الدائم؛ يلزم تطبيق الترحيل السحابي واختبار الأجهزة كما في تقرير الغياب التلقائي أعلاه.
4. **الأداء والأجهزة الخارجية.** يستمر تحذير حجم حزمة الإدارة فوق 500 kB؛ ما زال قياس أجهزة المستخدمين والكاميرا والطباعة والتكاملات الخارجية مطلوبًا.

لم تُغيّر بيانات إنتاج ولم تُرسل رسائل أو تُرفع ملفات إلى خدمات خارجية. احتُفظ بتعديلات واتساب السابقة، وأُعيدت المخرجات المتتبعة التي ولّدتها أوامر البناء إلى حالتها قبل الجولة.
