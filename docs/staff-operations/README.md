# إدارة المعلمين وجدول الانتظار

هذه الوحدة هي النواة المحلية التي ستستقبل بيانات «حضوري» و«مدرستي» مستقبلاً، لكنها تعمل الآن دون أي اتصال خارجي.

## القدرات الحالية

- سجل معلمين يتضمن الاسم والتخصص والحد الأسبوعي للانتظار والحالة النشطة.
- تعطيل المعلم دون حذف تاريخه.
- تسجيل حالة يومية: حاضر، متأخر، أو غائب.
- استيراد جدول أسبوعي من Excel بعد معاينة كاملة؛ لا يُحفظ أي صف إذا احتوى الملف خطأ واحداً.
- كشف تعارض المعلم وتعارض الصف/الفصل في اليوم والحصة نفسها.
- توليد مقترح تغطية للحصص المسندة إلى المعلمين الغائبين.
- استبعاد المعلم غير المسجل حضوره، أو الغائب، أو غير النشط، أو المرتبط بحصة، أو الذي بلغ حده الأسبوعي.
- منع تكليف المعلم نفسه بحصتين متزامنتين.
- ترتيب المرشحين حسب الأقل تكليفاً في الأسبوع، ثم مطابقة التخصص، ثم العبء اليومي.
- رفض اعتماد أي خطة تحتوي حصة بلا بديل، حتى عند العبث بملخص الخطة.
- إعادة التحقق من بيانات اليوم لحظة الاعتماد؛ إذا تغير الحضور أو الجدول تصبح الخطة القديمة غير صالحة.
- تخزين IndexedDB مستقل، وتسجيل كل تعديل مع حدث تدقيق ومقارنة إصدار ذرية تمنع سباقات التبويبات.

## قالب ملف الجدول

الورقة الأولى هي التي تُقرأ. يقبل النظام عناوين عربية أو إنجليزية:

| الحقل | أمثلة العنوان |
|---|---|
| المعلم | `معرف المعلم` أو `اسم المعلم` أو `Teacher ID` |
| اليوم | `اليوم` أو `Day` |
| الحصة | `الحصة` أو `Period` |
| المادة | `المادة` أو `Subject` |
| الصف | `الصف` أو `Class` |
| الفصل | `الفصل` أو `Section` |

الأيام المدعومة: الأحد إلى الخميس، والحصص من 1 إلى 12. تُقبل الأرقام العربية مثل `٢`.
تُطابق معرفات المعلمين حرفيًا بعد إزالة المسافات الخارجية فقط؛ لا يعد `t-1` و`t_1` معرفًا واحدًا، ويُرفض الصف إذا تعارض الاسم مع المعرف.

## قواعد التشغيل

1. أضف المعلمين أولاً، ويفضل استخدام معرف ثابت لكل معلم.
2. ارفع ملف الجدول وراجع كل حصة والأخطاء قبل الاعتماد؛ الملف الفارغ أو المتعارض لا يمكن اعتماده.
3. سجّل حالة جميع المعلمين لليوم؛ لا يدخل قائمة البدلاء إلا من سُجل «حاضر» أو «متأخر» صراحةً.
4. ولّد جدول الانتظار وراجع كل بديل وسبب اختياره.
5. لا يمكن اعتماد الخطة إذا بقيت حصة بلا تغطية.
6. أي تعديل في الحضور أو الجدول بعد التوليد يفرض توليد خطة جديدة.

## حدود المرحلة

- البيانات محلية على الجهاز وغير متزامنة مع السحابة حتى تُضاف جداولها وسياسات RLS رسمياً.
- لا يوجد ربط مباشر مع حضوري أو مدرستي في هذه المرحلة.
- «المتأخر» يُسجل كحاضر متأخر ولا يحجب المعلم عن التغطية آلياً؛ ستضاف قواعد الفترات عند توفر بيانات وصول موثوقة.
- تغيير البديل يدوياً وتصدير جدول الانتظار للطباعة/Excel من خطوات المرحلة التالية.
