# تشغيل خادم واتساب حاضر على جهاز ماك

الماك يصبح الخادم: الحاوية تعمل محلياً على `127.0.0.1:5001`، ونفق Cloudflare
يخرج من الجهاز إلى شبكة Cloudflare ويوصل نطاقاً فرعياً ثابتاً إليها. لا يُفتح
أي منفذ على الراوتر، ولا يحتاج الجهاز عنوان IP ثابتاً ولا موقعاً ثابتاً.

```
حاضر (Vercel)
   └─ /api/whatsapp            دالة خادم: تتحقق من الجلسة والصلاحية، وتحقن X-API-Key
        └─ https://<نطاقك>     نفق Cloudflare
             └─ cloudflared على الماك
                  └─ http://127.0.0.1:5001   حاوية واتساب
```

المتصفح لا يرى المفتاح في أي مرحلة.

## التجهيز لمرة واحدة

```bash
# 1) النفق — يفتح متصفحك لتسجيل الدخول واختيار النطاق
./setup-tunnel.sh wa.example.com

# 2) التشغيل التلقائي
./install.sh

# 3) اختبار من طرف الإنترنت
./verify-tunnel.sh wa.example.com
```

## التشغيل اليومي

```bash
hader-serverctl status       # حالة كل طبقة
hader-serverctl serve on     # وضع الخدمة: النظام لا ينام، والشاشة تنطفئ
hader-serverctl serve off    # إنهاء وضع الخدمة
hader-serverctl up           # تشغيل يدوي (Colima + الحاوية)
hader-serverctl down         # إيقاف الحاوية — الحجوم وجلسة واتساب تبقى
hader-serverctl logs 60      # آخر 60 سطراً من سجل المحرك
```

## ما يبدأ تلقائياً وما لا يبدأ

| | |
|---|---|
| `com.hader.whatsapp-stack` | Colima + الحاوية، مع إشراف كل 20 ثانية وتباعد تصاعدي عند الفشل |
| `com.hader.whatsapp-tunnel` | `cloudflared tunnel run` — يعيد الاتصال بنفسه عند انقطاع الشبكة |
| وضع الخدمة (منع السكون) | **لا يبدأ تلقائياً** — تشغّله أنت بـ `serve on`، وهو قرارك لا قرار النظام |

**بعد إعادة تشغيل الجهاز يلزم إدخال كلمة مرور الحساب مرة واحدة على شاشة الإقلاع.**
هذان وكيلا تشغيل (LaunchAgents) يعيشان في جلسة المستخدم لا في نطاق النظام، لأن
Colima و Docker يعملان بملفات المستخدم — وتشغيلهما كجذر يفصلهما عن الحجوم التي
تحمل جلسة واتساب. و FileVault مفعّل على هذا الجهاز، فالدخول التلقائي غير ممكن
أصلاً. بعد تلك الكلمة الواحدة يبدأ كل شيء بلا تدخل.

## السكون وغطاء الجهاز

`serve on` يمسك تأكيد `PreventUserIdleSystemSleep` عبر `caffeinate -i -m -s`،
فيبقى النظام مستيقظاً وتنطفئ الشاشة كالمعتاد (لا نمرّر `-d` عن قصد).

**إغلاق الغطاء ينيم الجهاز ويقطع الخدمة.** هذا الماك ليس موصولاً بشاشة خارجية،
ووضع clamshell على أجهزة Apple Silicon يتطلب طاقة **و** شاشة خارجية أو لوحة
مفاتيح خارجية. بلا ذلك لا يوجد إعداد يُبقي الخدمة عاملة والغطاء مغلق. الخيارات:

- اترك الغطاء مفتوحاً والجهاز موصولاً بالكهرباء — والشاشة تنطفئ وحدها.
- أو صِل شاشة/لوحة مفاتيح خارجية إن أردت إغلاق الغطاء.

## الإيقاف والتراجع

```bash
hader-serverctl serve off    # أعد سلوك السكون الطبيعي
./uninstall.sh               # أزل التشغيل التلقائي (لا يحذف الحاوية ولا الجلسة)
hader-serverctl down         # أوقف الحاوية
```

الحجوم `hader-whatsapp-session` و `hader-whatsapp-data` لا تُحذف بأي من هذه
الأوامر. حذفها يعني مسح رمز QR من جديد.

## السجلات

```
~/.hader/serverctl.log   قرارات الإشراف (تشغيل، فشل، تعافٍ)
~/.hader/tunnel.err.log  سجل cloudflared
~/.hader/stack.err.log   أخطاء وكيل التشغيل
hader-serverctl logs     سجل محرك واتساب داخل الحاوية
```

## المفتاح السري

يعيش في `.env` داخل مجلد المشروع بصلاحية `600`، وهو مستبعد من git. تقرأه
الحاوية عند إنشائها، وتقرأه دالة Vercel من متغيرات بيئتها. لا يوجد في أي
متغير يبدأ بـ `VITE_`، ولا في `localStorage`، ولا في أي سجل.

لنسخه إلى الحافظة عند ضبط متغيرات Vercel (بلا طباعته على الشاشة):

```bash
grep '^WHATSAPP_API_KEY=' ~/Downloads/Hader-ma-main/.env | cut -d= -f2- | tr -d '\n' | pbcopy
```
