# HADER AI PACKAGE - حزمة الترحيل والتوثيق

## 00-README.md
**وصف النظام:**
نظام **حاضر (Hader)** هو حل متكامل لإدارة الحضور والانصراف، السلوك، والمتابعة المدرسية. يهدف النظام إلى أتمتة عمليات رصد الغياب، التأخير، والاستئذان، مع توفير واجهات متعددة لخدمة الأدوار المختلفة في المدرسة (الإدارة، المشرفين، أولياء الأمور، والطلاب عبر الكشك الذكي).

يتميز النظام بدعم المزامنة الفورية (Real-time Sync) والعمل بوضع "غير متصل" (Offline-first) جزئياً، مع تكامل قوي مع واتساب وتليجرام للإشعارات الفورية.

---

### المستخدمين والأدوار (User Roles)
1.  **مدير النظام (Site Admin):** كامل الصلاحيات لجميع المدارس والإعدادات.
2.  **مدير المدرسة (School Admin):** إدارة الطلاب، المعلمين، الفصول، والإعدادات الخاصة بالمدرسة.
3.  **المشرف العام (Supervisor Global):** متابعة الحضور والتقارير على مستوى المدرسة.
4.  **مشرف الصف (Supervisor Class):** متابعة فصول محددة (رصد غياب، تواصل مع أولياء الأمور).
5.  **المراقب (Watcher):** دور مخصص لرصد الحضور اليدوي عند البوابات أو الفصول.
6.  **وضع الكشك (Kiosk):** واجهة ذاتية الخدمة للطلاب لتسجيل الحضور والتأخير ومسح الباركود.
7.  **ولي الأمر (Guardian):** استقبال الإشعارات ومتابعة حالة الأبناء (مخطط مستقبلاً كواجهة).

---

### أهم التدفقات (Key Flows)
1.  **تسجيل الحضور (Attendance):**
    *   عبر الكشك (مسح الباركود).
    *   عبر المشرف/المراقب (رصد يدوي سريع).
    *   استيراد ملفات Excel.

2.  **الاستئذان والخروج (Exits):**
    *   تسجيل طلب استئذان.
    *   طباعة تصريح خروج.
    *   تسجيل عودة الطالب.

3.  **المزامنة (Sync):**
    *   نقل البيانات بين الأجهزة المحلية وقاعدة البيانات السحابية (Supabase).
    *   معالجة التعارضات وتحديث الإحصائيات لحظياً.

4.  **التقارير (Reports):**
    *   تقارير يومية/شهرية للحضور والغياب.
    *   تقارير المخالفات السلوكية.

5.  **الإشعارات (Notifications):**
    *   إرسال رسائل واتساب تلقائية عند الغياب/التأخير.
    *   إشعارات تليجرام للإداريين.
