# HADER AI PACKAGE - قائمة الشاشات

## 07-UI-SCREENLIST.md

### 1. الشاشات العامة (Public/Common)
*   **Login Screen:** تسجيل الدخول (اسم مستخدم/كلمة مرور).
*   **Landing/Home:** توجيه المستخدم حسب الصلاحية (Redirector).
*   **404 Not Found:** صفحة خطأ مخصصة مع زر عودة.

### 2. شاشات الكشك (Kiosk Mode)
*   **Idle Screen:** شاشة التوقف (تعرض الوقت، التاريخ، وشعار المدرسة).
*   **Scan Screen:** كاميرا مفعلة لمسح الباركود.
*   **Success Feedback:** شاشة خضراء (تم التحضير) + تفاصيل الطالب (الاسم، الوقت).
*   **Warning Feedback:** شاشة صفراء (متأخر) + وقت التأخير.
*   **Error Feedback:** شاشة حمراء (طالب غير موجود / خطأ).
*   **Offline Indicator:** شريط علوي يظهر حالة الاتصال.

### 3. شاشات المشرف/المراقب (Supervision)
*   **Class Selection:** قائمة لاختيار الصف والفصل.
*   **Student List (Watcher):** قائمة طلاب الفصل مع أزرار سريعة (حاضر/غائب/تأخير).
*   **Quick Search:** شريط بحث سريع للوصول لطالب معين.

### 4. لوحة التحكم (Admin Dashboard)
*   **Main Dashboard:** إحصائيات عامة (رسم بياني للحضور، عدد الغياب اليوم، المتأخرين).
*   **Live Feed:** شريط جانبي يظهر آخر الحركات (فلان حضر، فلان خرج).
*   **Quick Actions:** أزرار للإجراءات السريعة (إرسال نداء، طباعة تقرير).

### 5. شاشات الإدارة (Admin Pages)
*   **Students Manager:** جدول الطلاب (بحث، فرز، إضافة، استيراد Excel، تعديل، حذف).
*   **Attendance Log:** سجل الحضور التاريخي (فلترة بالتاريخ، الطالب، الحالة).
*   **Reports Center:** توليد التقارير (يومي، شهري، حسب الفصل) وتصديرها.
*   **Settings:**
    *   **General:** اسم المدرسة، الشعار.
    *   **Timing:** إعدادات وقت الطابور، بداية الحصة الأولى، وقت التأخير.
    *   **Integration:** إعدادات ربط WhatsApp/Telegram.
    *   **Backup:** النسخ الاحتياطي واستعادة البيانات.

### 6. شاشات الخروج (Exits)
*   **Exit Request:** نموذج طلب خروج (بحث طالب، اختيار سبب).
*   **Active Exits:** قائمة الطلاب حالياً خارج المدرسة.
*   **History:** سجل الخروج السابق.
