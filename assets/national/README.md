# National identity artwork

Local PNG assets copied from the user-provided “بنرات تفاعلية متحركة (2)” package:

- `heritage.png`: `tiles/r2_1.png`
- `growth.png`: `tiles/r5_4.png`

The application uses the images as decorative artwork. It does not run the supplied HTML, `support.js`, or the cell animation engine. Copy is an application design treatment, with no year-specific official slogan or logo claim. Vite bundles the images locally for desktop and web builds.

The optional settings live under `kiosk_settings.national_identity`: `enabled` controls the attendance kiosk; `app_enabled` controls the shared application banner and login; `reduced_motion` freezes decorative motion. All default to off. Disabling the identity preserves the saved kiosk theme and operational settings.
